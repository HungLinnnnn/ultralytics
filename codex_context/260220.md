# Codex Plan — YOLOv8-Seg + SSM-Net (PAN-like)  
**Key choices requested**
- **Bottom-up (P3→P4) GateConcat guide = F4** (top-down P4 feature)
- **Bottom-up (P4→P5) GateConcat guide = G5** (Mamba output at P5)

This plan is written so you can paste to Codex and implement in Ultralytics.

---

## 0) Target: Keep PAN topology, replace ops
We keep YOLOv8 neck topology:
- Top-down: P5→P4→P3
- Bottom-up: P3→P4→P5

We replace:
- `nn.Upsample`  → **BDFWarpUp** (high-guided warp)
- `Concat` (top-down) → **SGF** (spectral gated fusion, residual)
- `Concat` (bottom-up) → **GateConcat** (selective feedback routing)

We also inject:
- **LowAggP5 + MambaCM** to create global anchor at P5: **G5**

Outputs to head:
- **F3_out, F4_out, F5_out** (PAN-like final)

## 1) New modules to implement/export
Create a new file (e.g., `ultralytics/nn/modules/ssmnet_pan.py`) and export classes in `ultralytics/nn/modules/__init__.py`.

### 1.1 LLDLow / LLDHigh (frequency decomposition)
Purpose: decompose feature F into low/high
- Low: `L = LowPass(F)`
- High: `H = F - L` (or a learned high extractor, but residual is simplest & stable)

**LLDLow(in_ch, k=3, mode="dwconv")**
- Depthwise conv (groups=in_ch), kernel k, padding k//2
- Optional GN/LN (recommended if batch small)
- Output: L, shape same as F

**LLDHigh(in_ch, mode="residual")**
- Input: (F, L)
- Output: H = F - L

> NOTE: If you already have `GaborLLDLow/GaborLLDHigh`, reuse them. Ensure output channels match input channels unless you explicitly project later.

### 1.2 LowAggP5 (cross-scale low aggregation to P5 grid)
Purpose: bring L3, L4 to P5 resolution, project, concat
Inputs: L3 (P3), L4 (P4), L5 (P5)
Steps:
- L3_5 = DownAA(L3, factor=4)  # P3→P5
- L4_5 = DownAA(L4, factor=2)  # P4→P5
- proj3 = Conv1x1(L3_5 -> d)
- proj4 = Conv1x1(L4_5 -> d)
- proj5 = Conv1x1(L5   -> d)
- Z5 = Concat([proj3, proj4, proj5], dim=1)  # channel concat
Output: Z5 at P5 grid, channels = 3d

**DownAA** recommended:
- AvgPool2d with kernel=stride=factor (stable)
- or stride depthwise conv + smoothing (optional)

### 1.3 MambaCM (global topology mixer at P5)
Purpose: refine Z5 (P5 grid) into global semantic anchor G5
Input: Z5 (B, 3d, H5, W5)
Output: G5 (B, d, H5, W5)  (or keep (B, 3d) and project; but prefer B,d)

Implementation options:
- reference: Mamba-yolo (/r13922151/ultralytics/Mamba-YOLO)

### 1.4 BDFWarpUp (high-guided warping upsample)
Purpose: replace blind upsample with offset-guided warp
Inputs:
- src: source feature at lower res (P5 or P4)
- high_t: high-frequency at target scale (H4 for P5→P4, H3 for P4→P3)
- low_t: optional low-frequency at target scale (L4 or L3) for stability (recommended)
Output:
- aligned feature at target resolution

Algorithm:
1) src_up = interpolate(src, scale_factor=2, mode="nearest" or bilinear)
2) offset_raw = offset_net( concat([high_t, proj(low_t), proj(src_up)]) )
3) offset = max_offset * tanh(offset_raw)
4) aligned = grid_sample(src_up, base_grid + offset)

Stabilization MUST:
- last conv of offset_net weight=0, bias=0  (identity init)
- max_offset default 1.0
- optional TV smooth loss on offset during training

### 1.5 SGF (top-down fusion)
Purpose: fuse aligned global M with local low B, using high E to sharpen boundaries
Inputs: (M, B, E)
- M: aligned global feature (A4 or A3)
- B: local low feature (L4 or L3)
- E: high edge feature (H4 or H3)

Compute:
- w_m = sigmoid(conv1x1(M))       -> shape (B,1,H,W)
- B'  = B * w_m
- w_e = 1 + tanh(conv1x1(E))      -> shape (B,1,H,W)
- M'  = M * w_e
- fused = conv1x1(concat([M', B'], dim=1))
- output = M + alpha * fused      # residual safety
  - alpha init = 0.0 or 0.1 (learnable scalar or fixed)

Output: F4_in or F3_in (channels = c_out)

### 1.6 GateConcat (bottom-up fusion, requested guides)
Purpose: filter bottom-up feedback before concat

**GateConcat(x, y, guide)**
- x: bottom-up downsampled feature (Down(F3) or Down(F4_out))
- y: lateral feature (F4 for P4 stage; S5 for P5 stage)
- guide: provided separately:
  - P4 stage guide = F4  (requested)
  - P5 stage guide = G5  (requested)

Gate (spatial, stable):
- w = sigmoid(conv1x1(guide))  # (B,1,H,W)
- x_gated = x * w
- out = concat([x_gated, y], dim=1)

Initialization:
- conv1x1 bias = +2.0 (so w≈0.88 initially, pass-through)
- weight init small (default ok)

Output channels:
- c_out = Cx + Cy

- LLDHigh: c2 = c(F)  (high same ch)

- MambaCM: c2 = d

- GateConcat: c2 = c_x + c_y

> Avoid Lazy modules in any of these; Ultralytics computes parameter counts in parse_model.

## 3) PAN-like Neck Flow (Step-by-step)
Let official backbone indices:
- P3 = layer 4
- P4 = layer 6
- P5 = layer 9 (after SPPF)

### 3.1 LLD decomposition
- L3 = LLDLow(P3)
- H3 = LLDHigh(P3, L3)
- L4 = LLDLow(P4)
- H4 = LLDHigh(P4, L4)
- L5 = LLDLow(P5)
- (H5 optional, unused)

### 3.2 Global anchor at P5
- Z5 = LowAggP5(L3, L4, L5, d)
- G5 = MambaCM(Z5)                 # (B,d,H5,W5)
- S5 = Conv1x1(Concat(G5, L5))     # semantic source for top-down (channels = C5_td)

### 3.3 Top-down stage 1: P5→P4
- A4 = BDFWarpUp(src=S5, high_t=H4, low_t=L4, max_offset)
- F4_in = SGF(M=A4, B=L4, E=H4, c_out=C4_td, residual=True)
- F4 = C2f(F4_in)                  # top-down P4 output

### 3.4 Top-down stage 2: P4→P3
- A3 = BDFWarpUp(src=F4, high_t=H3, low_t=L3, max_offset)
- F3_in = SGF(M=A3, B=L3, E=H3, c_out=C3_td, residual=True)
- F3 = C2f(F3_in)                  # top-down P3 output

### 3.5 Bottom-up stage 1: P3→P4 (Guide = F4)
- D4 = Down(F3)                    # stride 2 conv or AvgPool+Conv
- BU4 = GateConcat(x=D4, y=F4, guide=F4)    # requested guide
- F4_out = C2f(BU4)

### 3.6 Bottom-up stage 2: P4→P5 (Guide = G5)
- D5 = Down(F4_out)
- BU5 = GateConcat(x=D5, y=S5, guide=G5)    # requested guide
- F5_out = C2f(BU5)

### 3.7 Head
- Segment inputs = [F3, F4_out, F5_out]

## 4) YAML (Ultralytics) — PAN-like SSM-Net
Below is a concrete YAML skeleton (you may adjust channels per scale).
Assume yolov8n-seg base channels:
- P3 ch ≈ 256*w
- P4 ch ≈ 512*w
- P5 ch ≈ 1024*w
Ultralytics scales will shrink actual ch (n: w=0.25).

```yaml
# yolov8-seg-ssm-pan.yaml
nc: 80
scales:
  n: [0.33, 0.25, 1024]
  s: [0.33, 0.50, 1024]
  m: [0.67, 0.75, 768]
  l: [1.00, 1.00, 512]
  x: [1.00, 1.25, 512]

backbone:
  - [-1, 1, Conv, [64, 3, 2]]          # 0 P1/2
  - [-1, 1, Conv, [128, 3, 2]]         # 1 P2/4
  - [-1, 3, C2f, [128, True]]          # 2
  - [-1, 1, Conv, [256, 3, 2]]         # 3 P3/8
  - [-1, 6, C2f, [256, True]]          # 4 P3
  - [-1, 1, Conv, [512, 3, 2]]         # 5 P4/16
  - [-1, 6, C2f, [512, True]]          # 6 P4
  - [-1, 1, Conv, [1024, 3, 2]]        # 7 P5/32
  - [-1, 3, C2f, [1024, True]]         # 8
  - [-1, 1, SPPF, [1024, 5]]           # 9 P5

head:
  # --- LLD ---
  - [4, 1, LLDLow,  [3]]               # 10 L3
  - [[4, 10], 1, LLDHigh, []]          # 11 H3

  - [6, 1, LLDLow,  [3]]               # 12 L4
  - [[6, 12], 1, LLDHigh, []]          # 13 H4

  - [9, 1, LLDLow,  [3]]               # 14 L5
  - [[9, 14], 1, LLDHigh, []]          # 15 H5 (optional)

  # --- LowAggP5 + Mamba ---
  - [[10, 12, 14], 1, LowAggP5, [256, True]]   # 16 Z5 (3d channels on P5 grid)
  - [16, 1, MambaCM, [256]]                    # 17 G5 (d channels on P5 grid)

  # --- Build S5 (P5 semantic source) ---
  - [[17, 14], 1, Concat, [1]]          # 18 (G5||L5)
  - [-1, 1, Conv, [256, 1, 1]]          # 19 S5  (set c_out appropriately)

  # --- Top-down P5->P4: Warp + SGF + C2f ---
  - [[19, 13, 12], 1, BDFWarpUp, [1.0]]         # 20 A4 (aligned to P4)
  - [[20, 12, 13], 1, SGF, [512, True, 0.0]]    # 21 F4_in (c_out=512, residual, alpha_init)
  - [-1, 3, C2f, [512]]                         # 22 F4

  # --- Top-down P4->P3: Warp + SGF + C2f ---
  - [[22, 11, 10], 1, BDFWarpUp, [1.0]]         # 23 A3 (aligned to P3)
  - [[23, 10, 11], 1, SGF, [256, True, 0.0]]    # 24 F3_in (c_out=256)
  - [-1, 3, C2f, [256]]                         # 25 F3

  # --- Bottom-up P3->P4: Down + GateConcat(guide=F4) + C2f ---
  - [-1, 1, Conv, [256, 3, 2]]                  # 26 D4 = Down(F3)
  - [[26, 22, 22], 1, GateConcat, []]           # 27 BU4 = GateConcat(x=D4, y=F4, guide=F4)
  - [-1, 3, C2f, [512]]                         # 28 F4_out

  # --- Bottom-up P4->P5: Down + GateConcat(guide=G5) + C2f ---
  - [-1, 1, Conv, [512, 3, 2]]                  # 29 D5 = Down(F4_out)
  - [[29, 19, 17], 1, GateConcat, []]           # 30 BU5 = GateConcat(x=D5, y=S5, guide=G5)
  - [-1, 3, C2f, [256]]                         # 31 F5_out (set channel to match head)

  # --- Segment head ---
  - [[25, 28, 31], 1, Segment, [nc, 32, 256]]   # 32
```

## YAML Notes (IMPORTANT)
	1.	The Conv outputs after concat must match expected channel sizes.
- Example above sets S5 to 256 channels; adjust to align with your C2f configs.
	2.	SGF args are: [c_out, residual(True/False), alpha_init]
	3.	GateConcat has no args in YAML; it infers channels from inputs and has internal gate_net on guide.

## 5) GateConcat — exact behavior (requested)

### P4 bottom-up
- x = Down(F3)  (layer 26)
- y = F4        (layer 22)
- guide = F4    (layer 22)

Compute:
- w = sigmoid(Conv1x1(guide))  → (B,1,H4,W4)
- x_gated = x * w
- out = concat([x_gated, y], dim=1)

### P5 bottom-up
- x = Down(F4_out) (layer 29)
- y = S5           (layer 19)
- guide = G5        (layer 17)  NOTE: guide is P5 grid already

Same formula.

Initialization:
- gate conv bias = +2.0 for pass-through early training.

Return offsets from BDFWarpUp during forward (optional) or store internally.
Compute:
- TV loss on offset at P4 and P3 warp.

### 6.2 Offset sanity check

First forward should yield mean(|offset|) ≈ 0.
