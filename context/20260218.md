# SSM-Net for YOLOv8-seg：Context.md（可直接複製給 Codex 實作）
> 目標：在 **Ultralytics YOLOv8-seg** 的既有 PAN-FPN head 上，最小侵入式地加入  
> **(1) Gabor-LLD 頻帶分解**、**(2) MambaCM 全局一致性**、**(3) BDFUpsample 邊界對齊上採樣**、**(4) SGF 頻譜門控融合**  
> 用來改善細胞 instance segmentation 的 **碎裂、內部孔洞、邊界模糊/錯位**。

---

## 0. 設計總覽（你要實作的四個模組）
### 模組清單
1) **GaborLLDLow**：可學低通（low-pass），輸出 `F_low`  
2) **GaborLLDHigh**：Laplacian residual + Gabor bank（方向性邊界證據），輸出 `F_high_guide`  
3) **MambaCM**：對 `F_low` 做全域一致性增強（SSM / Mamba-like），輸出 `F_low_enh`（可選輸出 interior prior）  
4) **BDFUpsample**：用 `F_high_guide + F_low_enh` 預測 offset，做對齊式上採樣  
5) **SGF**：Residual-gated fusion，取代原本的 Concat（避免高頻噪聲直接進來、避免 gate 乘死訊號）

### 你要修改的 YOLOv8-seg 插入點（只動最關鍵兩個 top-down）
- 原本 head 有兩次：
  - `P5 -> Upsample -> Concat(P4) -> C2f`
  - `P4 -> Upsample -> Concat(P3) -> C2f`
- 我們改成：
  - `P5_low -> BDFUpsample(guided by P4_high_guide + P4_low_enh) -> SGF -> C2f`
  - `P4_fused -> BDFUpsample(guided by P3_high_guide + P3_low) -> SGF -> C2f`
- bottom-up path（後半段 Conv down + concat）先維持 YOLOv8 原樣，確保可落地與穩定。

## 1) 模組 1：Gabor-LLD（以「可學低通 + Laplacian residual + Gabor evidence」定義）
### 1.1 動機（Motivation）
- 細胞分割同時要：  
  **(a) 宏觀一致性**：細胞本體要連通、內部不能破洞/碎裂  
  **(b) 微觀精確性**：邊界要貼合、上採樣不能位移
- 固定 wavelet（如 Haar）不一定匹配資料域；而一般卷積殘差也容易混入噪聲。
- 所以我們用：
  - **可學 low-pass** 生成穩定的「本體語意」`F_low`
  - **Laplacian residual** `R = F - F_low` 保留細節
  - **Gabor bank** 從 `R` 抽取方向性邊界證據，形成 `F_high_guide` 供 BDF/SGF 使用

### 1.2 數學設計（Formulation）
輸入特徵 `F ∈ R^{B×C×H×W}`

**(A) 可學低通：**
\[
F_{low} = LP_\theta(F)
\]

> 要求：`LP_θ` 行為可辨識為 smoothing（低通），避免學成任意濾波而破壞 low/high 語意。

**(B) Laplacian residual：**
\[
R = F - F_{low}
\]

**(C) Gabor 邊界證據（方向選擇性 band-pass）：**
\[
E_{gabor} = \text{GaborBank}(R)
\]
建議使用 magnitude / energy（避免相位符號不穩）：
\[
E = |E_{gabor}| \quad \text{或} \quad E=\sqrt{Re^2+Im^2}
\]

**(D) High guidance（給 offset / gate 用）：**
\[
F_{high\_guide} = \phi([R, E])
\]
其中 `φ` 用 1×1 Conv（可含 Norm+SiLU）做融合與降維。

### 1.3 架構與參數（可落地建議）
#### GaborLLDLow（輸出 F_low）
- `LP_θ` 建議實作：**Softmax Low-pass Kernel**（內容自適應但仍是低通）
  - 由 `F` 生成 `k×k` kernel logits（每 pixel）
  - `softmax` -> non-negative 且 sum-to-1
  - 做 depthwise 的局部加權平均（smoothing）
- 參數建議：
  - `k=5`（P5/P4）或 `k=3/5`（P3）
  - `channel_reduction r=4`（先降通道再生成 kernel，省算力）
  - `groups=C`（depthwise）

#### GaborLLDHigh（輸出 F_high_guide）
- `R = F - F_low`
- Gabor bank：`n_orient=4~8`，`n_scales=1~2`（總濾波數 8~16）
- 先 `C -> C/4` squeeze 後做 gabor，再用 1×1 回到 `Cg`（例如 C/2）
- 建議輸出通道：
  - `P3: Cg=128`
  - `P4: Cg=256`
  - `P5: Cg=256`（只作 guidance，不必跟 1024 一樣大）

### 1.4 輸入輸出（I/O）
- Input：`F ∈ R^{B×C×H×W}`
- Output low：`F_low ∈ R^{B×C×H×W}`
- Output high guidance：`F_high_guide ∈ R^{B×Cg×H×W}`

### 1.5 插入點（Insertion）
- 針對 YOLOv8-seg backbone 的輸出：
  - P3: layer 4（C=256）
  - P4: layer 6（C=512）
  - P5: layer 9（C=1024, after SPPF）
- 對每個尺度各自產生 `low` 與 `high_guide`，供 head 使用。

## 2) 模組 2：MambaCM（Mamba Consistency Module）
### 2.1 動機
- 只靠 CNN/PAN 的局部融合，容易造成同一顆細胞內部特徵不一致 → 破洞/碎裂
- 我們只對 **低頻** `F_low` 做全域建模：  
  低頻代表本體語意，較適合長距離整合；高頻細節不需要全圖依賴。

### 2.2 數學直覺（給初學者）
把 2D feature map 看成一串 token（序列），用「狀態遞推」把全局資訊累積到每個位置。

將 `F_low (B×C×H×W)` reshape 成 `X (B×N×C)`，N=H·W  
對序列做遞推（概念式）：
\[
h_t = A h_{t-1} + B x_t,\quad
y_t = C h_t
\]
再 reshape 回 2D 得到 `F_low_enh`

> 多方向掃描（SS2D 的常見作法）：左→右、右→左、上→下、下→上，再融合，可讓每像素“看見全圖”。

### 2.3 架構設計（可落地）
- **只放在 P4_low（C=512）**：成本/收益最佳
- 輸出：
  - `F_low_enh`：給 BDF/SGF 作為 semantic anchor
  - （可選）`P_int` interior prior：`sigmoid(conv1×1(F_low_enh))`  
    用來抑噪與正則 offset（若不想多 output，就在 SGF/BDF 內部做一個 1×1 conv 產生也可）

### 2.4 參數建議
- `d_state`：16 或 32（小一點，穩定）
- `expand`：2
- `scan_directions=4`
- `norm=LayerNorm`（對 token 版）
- `dropout=0~0.1`

### 2.5 I/O
- Input：`F_low(P4) ∈ R^{B×512×H×W}`
- Output：`F_low_enh(P4) ∈ R^{B×512×H×W}`

### 2.6 插入點
- 在 head 開始 top-down 之前，把 P4_low 經過 MambaCM：
  - 用作 P5->P4 的 BDF offset semantic anchor
  - 用作第一個融合（P4）SGF 的 mask gate 來源

## 3) 模組 3：BDFUpsample（Boundary-aware Deformable Flow Upsample）
### 3.1 動機
- 原本 `nn.Upsample(nearest)` 是盲目插值：邊界位置不會被修正 → 邊界糊/位移、instance 破碎
- 我們把上採樣改成：「先預測每個輸出位置要從輸入哪裡取樣（offset），再用可微取樣完成對齊」。

### 3.2 核心數學（流程三步）
假設要把 `F_deep (B×C×H×W)` 上採樣到 `2H×2W`

**(1) offset prediction：**（由高頻邊界證據 + 低頻語意錨定共同決定）
\[
\Delta p = s\cdot \tanh(\text{Conv}([G_{high},\;G_{low}]))
\]
- `G_high`：同尺度的 `F_high_guide`（例如 P4_high_guide）
- `G_low`：同尺度的 `F_low_enh`（P4_low_enh）
- `Δp ∈ R^{B×2×2H×2W}`（dx,dy）
- `tanh` + `s`：限制最大位移，穩定訓練

**(2) sampling grid：**
\[
p' = p + \Delta p(p)
\]

**(3) deformable sampling（grid_sample/bilinear）：**
\[
F_{up}(p)=\sum_{q\in\mathcal{N}(p')}w_q\cdot F_{deep}(q)
\]

### 3.3 為什麼不是抄 local similarity？
- 我們的 offset 解釋是：
  - `G_high` 提供 **幾何（邊界方向/位置）**
  - `G_low` 提供 **語意錨定（物體本體在哪）**
- offset 的約束與可解釋正則也建立在 **“低頻一致性 + 邊界幾何”**，不是用 “feature similarity” 的替換規則。

### 3.4 可解釋的 offset 正則（建議加在 loss）
> 若專案不方便加額外 loss，至少做 offset 限幅（tanh*s）+ offset smooth（TV）也行。

**(A) interior smoothness（內部平滑）：**
\[
\mathcal{L}_{smooth}=\sum |\nabla \Delta p|\cdot P_{int}
\]
`P_int` 可由 `sigmoid(conv(F_low_enh))` 得到（同尺度）

**(B) normal alignment（沿邊界法向）：**
- 由 `G_high`（Gabor）估計 dominant orientation -> 法向 `n(p)`
\[
\mathcal{L}_{normal}=\sum \left(1-\frac{\Delta p\cdot n}{\|\Delta p\|\|n\|+\epsilon}\right)
\]

### 3.5 參數設計
- `scale=2`
- `max_offset s = 2.0`（P5->P4）與 `s = 1.5~2.0`（P4->P3）
- offset conv：
  - `Conv( (Cg + C_low) -> 64 -> 2 )`（小 MLP/Conv stack）
- sampling：用 `grid_sample`（PyTorch 原生），注意 align_corners 設定一致（建議 False）

### 3.6 I/O
- Inputs：
  - `F_deep ∈ R^{B×C×H×W}`
  - `G_high ∈ R^{B×Cg×2H×2W}`（目標尺度）
  - `G_low ∈ R^{B×C_low×2H×2W}`（目標尺度）
- Output：
  - `F_up ∈ R^{B×C×2H×2W}`

## 4) 模組 4：SGF（Spectral-Gated Fusion, residual-gated）
### 4.1 動機
- YOLO 原本融合：`Concat(UpFeature, SkipFeature)`  
  會把淺層噪聲直接帶進來，也沒有尊重「語意 vs 細節」的差異。
- 我們要：  
  - 用 **語意** 抑制 **高頻噪聲**  
  - 用 **邊界證據** 銳化 **語意邊界**
  - 並避免 early training gate 直接把分支乘死 → 用 residual gate

### 4.2 數學設計（Residual Gate）
令：
- `M`：上採樣後的語意特徵（global / up path）
- `B`：高頻 guidance（local / boundary）
- `G_low`：低頻語意錨定（可用 `F_low_enh` 或其 1×1 投影）

**(A) Semantic gate（抑噪高頻）：**
\[
W_{mask} = \sigma(\text{Conv}([M,\;G_{low}]))
\]
\[
B' = B + \alpha\cdot (B\odot W_{mask})
\]

**(B) Boundary gate（銳化語意）：**
\[
W_{edge} = 1+\tanh(\text{Conv}(B'))
\]
\[
M' = M + \beta\cdot (M\odot W_{edge})
\]

**(C) 融合輸出：**
\[
F_{out} = \text{Conv}([M',\;B'])
\]

### 4.3 參數設計
- `α, β`：可學 scalar（初始化 0 或 0.1）
- `Conv`：建議 1×1（快、穩）
- `F_out` 通道：
  - 在 P4 融合後輸出 512（接 YOLO 的 C2f[512]）
  - 在 P3 融合後輸出 256（接 YOLO 的 C2f[256]）

### 4.4 I/O
- Inputs：
  - `M ∈ R^{B×C×H×W}`
  - `B ∈ R^{B×Cg×H×W}`
  - `G_low ∈ R^{B×C_low×H×W}`（可用 `F_low_enh` 或其投影）
- Output：
  - `F_out ∈ R^{B×C_out×H×W}`

# 5) 最終可落地 YOLOv8-seg YAML（在官方 YAML 基礎上改）
> 說明：
> - backbone 完全不動
> - 在 head 前半（top-down）插入 LLD / MambaCM / BDF / SGF
> - 後半 bottom-up 盡量沿用原始設計
> - Ultralytics YAML 允許「同一層 from 被多次引用」，所以我們用 **平行兩層**從同一個 backbone feature 生成 `low` 與 `high_guide`，避免 tuple output 難題。

## 5.1 新增的模組名稱（Codex 需要實作/註冊）
- `GaborLLDLow`
- `GaborLLDHigh`
- `MambaCM`
- `BDFUpsample`
- `SGF`

## 5.2 YAML（含逐層註解 + 對應官方 layer index）
```yaml
# Ultralytics YOLOv8-seg + SSM-Net head (top-down enhanced)
# backbone: 官方不變（0~9）

nc: 80
scales:
  n: [0.33, 0.25, 1024]
  s: [0.33, 0.50, 1024]
  m: [0.67, 0.75, 768]
  l: [1.00, 1.00, 512]
  x: [1.00, 1.25, 512]

backbone:
  - [-1, 1, Conv, [64, 3, 2]]        # 0-P1/2
  - [-1, 1, Conv, [128, 3, 2]]       # 1-P2/4
  - [-1, 3, C2f, [128, True]]        # 2
  - [-1, 1, Conv, [256, 3, 2]]       # 3-P3/8
  - [-1, 6, C2f, [256, True]]        # 4  (P3)
  - [-1, 1, Conv, [512, 3, 2]]       # 5-P4/16
  - [-1, 6, C2f, [512, True]]        # 6  (P4)
  - [-1, 1, Conv, [1024, 3, 2]]      # 7-P5/32
  - [-1, 3, C2f, [1024, True]]       # 8
  - [-1, 1, SPPF, [1024, 5]]         # 9  (P5)

head:
  # ---------- (A) Gabor-LLD on P3/P4/P5 ----------
  # P3 from layer 4
  - [4, 1, GaborLLDLow,  [k=5, r=4]]             # 10  P3_low:  B×256×H×W
  - [4, 1, GaborLLDHigh, [k=7, r=4, cg=128,
                          n_orient=4, n_scales=2, magnitude=True]]  # 11  P3_high_guide: B×128×H×W

  # P4 from layer 6
  - [6, 1, GaborLLDLow,  [k=5, r=4]]             # 12  P4_low:  B×512×H×W
  - [6, 1, GaborLLDHigh, [k=7, r=4, cg=256,
                          n_orient=4, n_scales=2, magnitude=True]]  # 13  P4_high_guide: B×256×H×W

  # P5 from layer 9
  - [9, 1, GaborLLDLow,  [k=5, r=4]]             # 14  P5_low:  B×1024×H×W
  - [9, 1, GaborLLDHigh, [k=7, r=4, cg=256,
                          n_orient=4, n_scales=2, magnitude=True]]  # 15  P5_high_guide (可不用, 預留)

  # ---------- (B) MambaCM on P4_low (semantic anchor) ----------
  - [12, 1, MambaCM, [c=512, d_state=16, expand=2, directions=4]]   # 16  P4_low_enh: B×512×H×W

  # ---------- (C) Top-down stage 1: P5 -> P4 ----------
  # 原本: Upsample(P5)->Concat(P4)->C2f
  # 改為: BDFUpsample(P5_low guided by P4_high_guide + P4_low_enh) -> SGF -> C2f

  - [[14, 13, 16], 1, BDFUpsample, [scale=2, max_offset=2.0]]       # 17  U4: B×1024×(2H)×(2W)
  - [[17, 13, 16], 1, SGF, [c_out=512, residual_gate=True]]         # 18  F4_fuse_in: B×512×(2H)×(2W)
  - [-1, 3, C2f, [512]]                                             # 19  F4: (對應官方 layer12)

  # ---------- (D) Top-down stage 2: P4 -> P3 ----------
  - [[19, 11, 10], 1, BDFUpsample, [scale=2, max_offset=2.0]]       # 20  U3: B×512×(4H)×(4W)
  - [[20, 11, 10], 1, SGF, [c_out=256, residual_gate=True]]         # 21  F3_fuse_in: B×256×(4H)×(4W)
  - [-1, 3, C2f, [256]]                                             # 22  F3: (對應官方 layer15, P3/8-small)

  # ---------- (E) Bottom-up path：盡量沿用官方（用 F3/F4 與原 P5） ----------
  - [-1, 1, Conv, [256, 3, 2]]                                      # 23  downsample F3 -> P4 scale
  - [[-1, 19], 1, Concat, [1]]                                      # 24  cat head P4 (用我們的 F4)
  - [-1, 3, C2f, [512]]                                             # 25  P4/16-medium (對應官方 layer18)

  - [-1, 1, Conv, [512, 3, 2]]                                      # 26  downsample -> P5 scale
  - [[-1, 9], 1, Concat, [1]]                                       # 27  cat backbone P5 (保留官方 P5)
  - [-1, 3, C2f, [1024]]                                            # 28  P5/32-large (對應官方 layer21)

  - [[22, 25, 28], 1, Segment, [nc, 32, 256]]                       # 29  Segment(P3, P4, P5)
```

## 6) Codex 實作注意事項（Ultralytics 接法要點）
1.	YAML module 註冊：需要把自訂 module 加到 Ultralytics 的 module registry（通常是 ultralytics/nn/modules 與 parse_model 的可解析表）
2.	BDFUpsample 的 inputs：此 YAML 設計成 3-input：[F_deep, G_high, G_low]
3.	SGF 的 inputs：此 YAML 設計成 3-input：[M, B, G_low]
4.	通道對齊
    - BDFUpsample 輸出通道 = C_deep（不改通道，只改空間）
    - SGF 內部會融合後用 1×1 conv 輸出 c_out（對接後續 C2f）
5.	GaborLLDHigh：請務必做 magnitude=True 或 abs()，避免相位符號導致 gate/offset 不穩

## 8) 你最後要餵給 Codex 的一句總結（讓它照這份做）

在 YOLOv8-seg head 的兩個 top-down 融合點，把 nearest upsample + concat 替換成
BDFUpsample(F_deep=P5_low/P4_fused, guidance=HighGuide(P4/P3) + LowAnchor(P4_low_enh/P3_low)) + SGF(residual gated fusion)；
在 head 前先用 Gabor-LLD 產生每個尺度的 low 與 high_guide，並只在 P4_low 加一個 MambaCM 產生低頻語意錨定。
